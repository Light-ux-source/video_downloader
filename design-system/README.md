# 设计系统

本项目界面风格为**暗色霓虹终端 / HUD**，实际生效的设计令牌在
[`frontend/src/styles/tokens.css`](../frontend/src/styles/tokens.css)——
那是**唯一的真相来源**。本目录保留设计阶段的决策记录。

> 修改样式请以 `tokens.css` 为准。

## 设计目标

需求明确要求「前端页面需要足够独特，不要千篇一律」。因此刻意避开
"顶部导航栏 + 卡片网格 + 圆角按钮"的通用模板脸，采用**控制台 / HUD** 隐喻：

- 信息密度高，符合"下载工具"的理性气质
- 视觉辨识度强（暗底 + 霓虹 + 等宽字体 + 扫描线）
- 用设计约束兜住可读性与无障碍，而不是牺牲可用性换观感

### 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题 / 数字展示 | **Orbitron** | 科技感，用于品牌名与关键数字 |
| 正文 / 代码 / 日志 | **JetBrains Mono** | 等宽，含 `PingFang SC`/`Microsoft YaHei` 中文回退 |

| 项 | 值 |
|---|---|

## 独特元素（区别于通用模板的地方）

| 元素 | 做法 | 目的 |
|---|---|---|
| **不对称三栏** | 左侧 236px 窄遥测栏 + 中央工作台 + 下方任务流 | 打破居中对称，视觉重心偏左 |
| **命令行式输入框** | `▸` 提示符、等宽字体、聚焦发光；解析时底部扫描线锁相动画 | 强化"工具"感 |
| **ASCII 块状进度条** | `████████░░` + 并排数字遥测（速度/ETA/分片） | 比通用圆角进度条更直观、更硬核 |
| **任务即终端日志** | 每条任务可展开查看 yt-dlp 原始输出流 | 便于排障，气质统一 |
| **信号锁定扫描动画** | 解析中的 `sweep` 关键帧 | 让"正在解析"有明确反馈 |
| **角落刻度 / 细网格背景** | 径向遮罩的网格线 + 面板顶部渐变 | 增加层次，不用插图 |
| **脉冲状态点** | 遥测栏 `LINK UP` 呼吸灯 | 传达"服务在线" |

## 无障碍约束（硬指标）

| 项 | 做法 |
|---|---|
| 对比度 | 正文/次级文字对背景 ≥ 4.5:1；弱化文字仅用于非关键信息 |
| 焦点可见 | 全局 `:focus-visible` 2px 霓虹描边 + 2px 偏移 |
| 减弱动效 | `@media (prefers-reduced-motion: reduce)` 下动画与过渡降至 0.001ms |
| 键盘可达 | 全部交互元素可 Tab 到达；`/` 聚焦输入框、`Esc` 清除解析结果 |
| 图标 | 统一 SVG（`Icon.vue`），不使用 emoji，均带 `aria-hidden` 或可访问名 |
| 触控目标 | 主按钮最小高度 36px、图标按钮 36×36，列表项可点区域 ≥ 40px |
| 表单 | 每个控件有可见 label；错误信息就近展示并 `role="alert"` |
| 进度 | 视觉用 ASCII 条，同时提供 `role="progressbar"` 的 `sr-only` 元素 |
| 响应式 | 验证断点 375 / 768 / 1024 / 1440；移动端遥测栏转为静态块 |

## 风格来源

设计方案参考了 `ui-ux-pro-max` 技能数据库中 **Cyberpunk UI** 风格定义：

> Neon, dark mode, terminal, HUD, sci-fi, glitch, dystopian, futuristic, matrix, tech noir
> 关键效果：霓虹辉光、扫描线叠加、等宽字体、终端质感

我们采纳了它的**风格方向与字体搭配（Orbitron + JetBrains Mono）**，
但配色改为自定义的青/紫双霓虹（而非它的 Matrix Green + Magenta），
原因是：
- 青紫对比在深色背景下长时间阅读更舒适
- 纯绿（`#00FF00`）在大面积使用时容易刺眼且显廉价
- 需要与"成功/警告/危险"三个语义色共存而不打架
